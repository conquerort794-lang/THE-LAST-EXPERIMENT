STEP 1 NOTES (how the project works)
- 3 files only: index.html, style.css, game.js. Canvas 2D, tile size T=32, zoom Z=1.5.
- Map = {t:[rows of tile ids], w, h}. buildWorld() (game.js ~line 45) makes a 60x44 map using a
  seeded RNG (rnd, seed=11). IMPORTANT: any extra rnd() call BEFORE the existing ones changes the
  whole existing map. buildAbyss() also uses rnd() AFTER buildWorld.
- Tile ids: 0 grass, 1 tree(solid), 2 water(solid), 3 path, 4 rock(solid), 5 wall(solid),
  6 house floor, 7 lab floor, 8 corrupted ground (unused base), 9 abyss floor.
  SOLID = Set([1,2,4,5]) at top of file. tile(v,x,y) draws each tile (~line 238).
  Ids 0/1/4 pick colours with `cor = x>=40` (corrupted palette).
- Zones are decided by X only: zoneOf(p) (~line 234): <20 Greenhaven, <40 Forgotten Village, else
  Corrupted Zone; inLab() special-cases the lab. render() ends with a per-zone colour tint (~line 316)
  whose default fallback is a dark-blue tint.
- Layout: river x~19-20; main road y=22-23 (x1..56); north path x30-31 y12-21; village houses at
  (24-29,13-18), (34-38,26-30), (24-28,27-31); cave (3-8,31-36); lab (45-57,5-16); border = tile 1.
- Enemies: ET table (~line 13), mk(type,x,y), updE() generic chase AI (supports `shoot` for ranged),
  drawE() draws each type by name, ZN = spawn rectangles per type, respawn() uses `mins` per type,
  initWorld() does the first spawn. 'wraith' is Abyss-only.
- Saves store only the player (P) in localStorage; the map is rebuilt each load, so map changes
  do not break saves.

STEP 2 DECISION (where to attach the marsh)
- The bottom border of the map (row y=43) is solid trees and nothing exists south of it.
- Chosen design: APPEND 24 new rows (y=44..67) to the existing map = the marsh, and open a gap in
  the old south border at x=30-31 with a path that runs from the main road (y=24) to y=43, then
  on into the marsh. x=30-31 is free between two village houses, so it reads as "the south road of
  the Forgotten Village leads to the marsh".
- Why: nothing existing is moved, spawn zones (y<=42) are untouched, camera/render/isSolid already
  use M.w/M.h so they adapt. Marsh uses its OWN private RNG so the old world layout stays identical.
- Marsh zone detection: p.y/T >= MY0 (MY0=44).
- New tile ids planned: 10 marsh ground, 11 murky water (solid), 12 shallows (walkable).
